Функции

Функция (function) это кусок кода с именем. Его пишут один раз, а вызывают сколько угодно раз с разными данными. print(), len(), pd.read_excel() тоже функции, их написали за нас.

Метафора

Функция это кофемашина. На входе зёрна и вода (аргументы), внутри рецепт (тело функции), на выходе чашка кофе (return). Всё, что машина делала внутри, остаётся внутри: когда она закончила, промежуточные переменные исчезают.

      Разница
      
print показывает, return отдаёт

      
Это самая частая путаница. print выводит число на экран для человека. return отдаёт число коду, который вызвал функцию. Если функция ничего не вернула, снаружи окажется None.

    

    

      

        
print: результат нельзя использовать дальше


def oil_per_shift(oil_day, shifts):
    print(oil_day / shifts)

result = oil_per_shift(1650, 2)   # на экране 825.0
print(result)                      # None

        
Коробка result пустая: None.

      

      

        
return: результат можно положить в коробку


def oil_per_shift(oil_day, shifts):
    return oil_day / shifts

result = oil_per_shift(1650, 2)   # на экране ничего
print(result)                      # 825.0

        
В коробке result лежит 825.0, с ним можно считать.

def main():
    df = pd.read_excel(DATA_FILE)
    print("Строк:", len(df))

if __name__ == "__main__":
    main()

    

    
def только записывает рецепт. Машина начинает работать, когда её вызывают по имени со скобками: main(). Вторая ошибка из той же серии: функция считает, но не возвращает результат. Снаружи получаем None и потом TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'.
