Списки и словари

Список (list) хранит много значений по порядку: все скважины объекта, добычу по дням. Словарь (dict) хранит значения под именами: одна запись о скважине, где у каждого числа есть подпись.

Метафора

Список это полка с пронумерованными ячейками, нумерация с 0. Словарь это картотека: на каждой карточке ярлык (ключ) и содержимое (значение). Карточку ищут по ярлыку, а не по номеру.

      Как это выглядит в коде
      
Главные операции

    

    


wells = ["T-101", "T-102", "T-201"]
print(wells[0])        # T-101, первая ячейка
print(wells[-1])       # T-201, последняя
print(wells[0:2])      # ['T-101', 'T-102']
print(len(wells))      # 3
wells.append("T-202")  # положить в конец
print("T-102" in wells)  # True, есть на полке


record = {"скважина": "T-101", "нефть": 531.4}
print(record["нефть"])          # 531.4
record["вода"] = 50.7           # новая карточка
print(record.get("газ", 0))     # 0, если ключа нет
for key, value in record.items():
    print(key, "=", value)

    

  


  

    

      Типичная ошибка
      
Счёт с единицы и ключ не той буквой

    

    

      
Так падает


wells = ["T-101", "T-102", "T-201"]
print(wells[3])       # IndexError: list index out of range
print(record["Нефть"])  # KeyError: 'Нефть'

      
Так работает


print(wells[2])        # третья ячейка имеет номер 2
print(wells[-1])       # последняя, сколько бы их ни было
print(record["нефть"])  # ключ буква в букву

    

    
В Excel строки считают с 1, в Python с 0. Ключ словаря должен совпадать полностью, включая регистр и пробелы. То же правило действует для названий колонок в pandas: df["Нефть_т"], а не df["нефть_т"].
