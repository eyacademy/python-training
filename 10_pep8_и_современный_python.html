PEP 8 и современный Python

PEP 8 это общепринятые правила оформления Python-кода: отступы, имена, пробелы, длина строки. Код по PEP 8 одинаково читают вы, коллеги и ИИ. Вручную следить за правилами не нужно, это делает ruff за одну команду.

Метафора

PEP 8 это шаблон оформления отчёта: одинаковые шрифты, поля и заголовки. Содержание от этого не меняется, но читать в разы проще. ruff это кнопка «применить шаблон».

Интерактив

До и после: тянем шторку

Слева код, как его иногда пишут наспех. Справа тот же код после ruff format, ruff check --fix и переименования. Тяните жёлтую шторку или ползунок, чтобы раскрыть одну из сторон. Потом выбирайте тему и смотрите, какие строки поменялись.

3.13Новый интерактивный режим (REPL)
        Цветное приглашение, редактирование нескольких строк целиком, история по стрелке вверх, F1 справка, F3 режим вставки кода. Выйти можно словом exit без скобок.
        
>>> oil = 1650
>>> for s in ["A", "B"]:
...     print(s, oil / 2)
A 825.0
B 825.0

      
3.13Цветные ошибки и новые подсказки
        Traceback раскрашен: тип ошибки и место выделены цветом. Python подсказывает правильное имя аргумента и предупреждает, если ваш файл называется как библиотека.
        
>>> "T-101 T-102".split(max_split=1)
TypeError: split() got an unexpected keyword argument 'max_split'. Did you mean 'maxsplit'?

      
3.14Подсветка синтаксиса прямо в REPL и подсказки к опечаткам
        Код в интерактивном режиме раскрашивается, пока вы печатаете. Опечатку в ключевом слове Python распознаёт и предлагает правильное.
        
whille True:
^^^^^^
SyntaxError: invalid syntax. Did you mean 'while'?

      
3.14Короче запись except и t-строки
        Несколько ошибок можно перечислить без скобок: except ValueError, TypeError:. Появились t-строки t"...": похожи на f-строки, но возвращают шаблон, а не готовый текст. Аналитику в работе пока хватит f-строк.
        
try:
    oil = float(text)
except ValueError, TypeError:
    oil = None

      Типичная ошибка
      
Файл назвали как библиотеку

    

    

      
Файл pandas.py или random.py


AttributeError: module 'random' has no attribute 'randint'
(consider renaming 'C:\Users\aigerim\ey_python\random.py'
since it has the same name as the standard library module
named 'random' and prevents importing that standard
library module)

      
Переименовать файл


random.py   →  dice_test.py
pandas.py   →  otchet_pandas.py

# и удалить папку __pycache__ рядом, если она есть

    

    
Python ищет модуль сначала в папке со скриптом. Файл pandas.py перекрывает настоящую библиотеку, и import pandas загружает ваш файл. Начиная с 3.13 Python сам подсказывает эту причину в тексте ошибки. Не называйте файлы pandas.py, numpy.py, random.py, json.py.
