Pandas и DataFrame

Pandas это библиотека для таблиц. Главный объект в ней DataFrame: таблица с колонками, строками и индексом. Всё, что вы делаете в Excel руками (фильтры, замены, сводные), pandas делает командами, которые можно запустить заново на новых данных.

Метафора

DataFrame это лист Excel в памяти Python. Колонки с заголовками, строки, слева номер строки (индекс). groupby это сводная таблица.

      Как это выглядит в коде
      
Весь пайплайн в одном месте

    

    


from pathlib import Path
import pandas as pd

path = Path("data") / "добыча_2026.xlsx"
df = pd.read_excel(path, sheet_name="Добыча")
df.info()                              # типы и пропуски

df["Объект"] = df["Объект"].str.strip().str.upper()
oil_text = df["Нефть_т"].astype(str)
oil_text = oil_text.str.replace(" ", "").str.replace(",", ".")
df["Нефть_т"] = pd.to_numeric(oil_text, errors="coerce")
df = df.drop_duplicates()

cols = ["Нефть_т", "Простой_ч"]
summary = df.groupby("Объект")[cols].sum()
summary.to_excel(Path("результаты") / "сводка.xlsx")

      

        
df это объект класса DataFrame. Класс это чертёж, объект это вещь по чертежу. type(df) ответит <class 'pandas.DataFrame'>. Поэтому у df есть свои команды через точку: df.info(), df.head(), df.groupby().

        
Колонка это Series. df["Нефть_т"] возвращает одну колонку. Её команды для текста живут в .str, для дат в .dt.

        
Типы в pandas 3. Текст показывается как str, смесь чисел и текста как object. Если колонка с числами стала object, в ней есть текст.

      

    

  


  

    

      Типичная ошибка
      
.str.replace на колонке, где числа вперемешку с текстом

    

    

      
Настоящие числа пропадают


df["Нефть_т"].str.replace(",", ".")
# 531.4    → NaN
# "1 234,5" → "1 234.5"
# 548.2    → NaN   (числа стали пустыми!)

      
Правильно


oil_text = df["Нефть_т"].astype(str)   # всё в текст
oil_text = oil_text.str.replace(" ", "")
oil_text = oil_text.str.replace(",", ".")
df["Нефть_т"] = pd.to_numeric(oil_text, errors="coerce")

    

    
.str работает только с текстом. Ячейки, где уже лежит число, он превращает в NaN без всякой ошибки. Проверяйте результат: количество пропусков до и после очистки через df["Нефть_т"].isna().sum(). Если оно выросло, что-то потерялось.

Данные: файл data/добыча_2026.xlsx, лист Добыча, колонки: Дата (2026-01-01 или текст "05.03.2026"), Объект ("КТЛ-1", " ЗВП ", "зсг"), Скважина ("T-101"), Нефть_т (531.4 или текст "1 234,5", есть пропуски), Простой_ч (0, 6). Данные условные.
Результат: таблица Объект, Нефть_т, Простой_ч и файл результаты/сводка.xlsx.
Правила: Объект через strip и upper; Нефть_т убрать пробелы, запятую заменить на точку, pd.to_numeric(errors="coerce"); удалить полные дубликаты; пропуски не заполнять нулями.
Ограничения: Python 3.14, pandas, openpyxl, пути относительные через pathlib, комментарии на русском, без лишних библиотек.
