Условия и циклы

Условие (if) выбирает, какой кусок кода выполнить. Цикл (for, while) повторяет кусок кода много раз. Вместе они заменяют ручную работу: проверить давление на 1 837 строках, пройти по всем скважинам.

Метафора

if/elif/else это развилка на дороге: Python проверяет таблички по очереди и едет по первой, где написано «верно». Цикл for это обход полки ячейка за ячейкой. while это «повторяй, пока условие верно».

      Как это выглядит в коде
      
Условие внутри цикла: так выглядит реальная проверка

    

    


pressures = {"T-101": 78.4, "T-102": 104.2, "T-201": 57.9}

for well, pressure in pressures.items():
    if pressure > 100:
        print(well, "высокое давление, проверить")
    elif pressure < 60:
        print(well, "низкое давление")
    else:
        print(well, "норма")

      

        
Двоеточие и отступ. После if, elif, else, for, while всегда двоеточие. Всё, что относится к ним, сдвинуто на 4 пробела. Отступ в Python работает как скобки.

        
Сравнения: >, <, >=, <=, == (равно), != (не равно). Одно = кладёт в коробку, два == сравнивают.

        
В pandas циклы по строкам почти не нужны. Там та же проверка пишется одной строкой для всей колонки: df[df["Давление_бар"] > 100].

      

    

  


  

    

      Типичная ошибка
      
Забыли отступ или двоеточие

    

    

      
Так падает


for well in wells:
print(well)


IndentationError: expected an indented block after 'for' statement on line 1. Python не знает, что повторять.

      
Так работает


for well in wells:
    print(well)


Тело цикла сдвинуто на 4 пробела. VS Code ставит их сам после Enter, если в конце строки есть двоеточие.
