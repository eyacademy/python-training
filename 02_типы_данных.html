Типы данных

Тип (type) говорит Python, что за значение лежит в переменной и что с ним можно делать. Числа складываются, текст склеивается. Число 10 и текст "10" выглядят похоже, но для Python это разные вещи.

Метафора

Тип это что за предмет в коробке: целое число, число с точкой, текст или да/нет. Функция type() позволяет заглянуть в коробку и узнать, что там.

Интерактив

Преобразования: int(), float(), str()

Из Excel и из input() числа часто приходят текстом. Введите текст, как он записан в ячейке, и посмотрите, что сделает каждая функция.

Правило: перед расчётом убираем пробелы и меняем запятую на точку. В pandas то же самое делает pd.to_numeric(..., errors="coerce") (страница 9).
Как это выглядит в коде

Проверяем тип и приводим к нужному

oil_text = "552.9"          # пришло из файла текстом
print(type(oil_text))       # <class 'str'>

oil = float(oil_text)       # текст → число с точкой
print(type(oil))            # <class 'float'>
print(oil * 2)              # 1105.8

shifts = int("2")           # текст → целое
label = "Смен: " + str(shifts)   # число → текст для подписи
print(label)                # Смен: 2

Три функции-переводчика. int() делает целое число, float() число с точкой, str() текст. Исходная переменная не меняется, новое значение нужно положить в коробку.

Для подписей удобнее f-строка. Запись f"Смен: {shifts}" сама превращает число в текст.

Округление. round(552.94, 1) даёт 552.9. Для отчёта округляем в конце, не на каждом шаге.

Типичная ошибка

Числа из файла оказались текстом

Результат неверный, ошибки нет
a = "552.9"     # из Excel пришёл текст
b = "531.4"
print(a + b)    # 552.9531.4

Python не упал, он склеил два текста. Такую ошибку легко пропустить, поэтому смотрите на тип: type(a), а в pandas df.info().

Правильно
a = float("552.9")
b = float("531.4")
print(a + b)    # 1084.3

Сначала переводим текст в числа, потом считаем. Если в ячейке "1 234,5", сначала .replace(" ", "").replace(",", ".").
