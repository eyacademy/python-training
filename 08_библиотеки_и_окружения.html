Библиотеки и окружения

Библиотека (library, пакет) это готовый код, который написали другие: pandas читает Excel, matplotlib рисует графики. Окружение (environment) это отдельная папка со своим Python и своим набором библиотек под конкретный проект.

Метафора

Библиотека это ящик с готовыми инструментами, import значит «достать ящик». Окружение это отдельный набор ящиков под проект, чтобы проекты не мешали друг другу: в одном pandas 3, в старом отчёте pandas 2, и оба работают.

Как понять, что библиотека не установлена

ModuleNotFoundError: что делать по шагам

Сообщение ModuleNotFoundError: No module named 'openpyxl' значит: в окружении, которое сейчас запускает код, такого ящика нет. Код при этом может быть правильным.

Проверьте, какое окружение активно.
В терминале слева в скобках имя: (ey). В VS Code внизу справа версия Python, щелчок по ней или команда «Python: Select Interpreter».
Проверьте пакет одной командой.
python -c "import openpyxl; print(openpyxl.__version__)"
Установите в это окружение.
conda install -c conda-forge openpyxl или pip install openpyxl
Перезапустите.
В Jupyter: Restart kernel. В терминале запустите скрипт заново.

Типичная ошибка

pip install внутри Python или не в том окружении

Так не работает
>>> pip install pandas
  File "<python-input-0>", line 1
    pip install pandas
        ^^^^^^^
SyntaxError: invalid syntax
Так работает
# в терминале, не в Python:
(ey) C:\Users\aigerim\ey_python> conda install pandas

# в ячейке Jupyter:
%pip install pandas

Команды установки пишут в терминал, а не в интерпретатор Python с приглашением >>>. Вторая частая беда: пакет поставили в base, а VS Code запускает окружение ey. Смотрите на имя в скобках перед приглашением.
